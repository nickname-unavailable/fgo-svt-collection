# FGO 从者实装图鉴

一个纯前端的 FGO 从者图鉴：**475 位已实装从者 + 12 个图鉴 NPC + 176 个卫星角色 + 232 个未实装人物**，
按职阶排列、支持四种方式搜索、点开能看每位从者的首次 Pick Up 与获取方式。

站点地址（GitHub Pages）：<https://nickname-unavailable.github.io/fgo-svt-collection/>

> 本仓库是**发布产物**（编译好的静态站点），不包含源码。

## 能做什么

**全量图鉴**
跟着日服名单走，图鉴编号 #1–#487 没有断号。头像全部本地化（487 张），断网也能看。
未实装的编号不会被跳过——它会留一个虚线空位待在原处，编号照显示。

**四种搜索入口**
名字（`阿尔托莉雅`）、图鉴编号（`#123`）、内部 id（`@100100`）、职阶（`saber`）。
匹配字高亮，结果数写在搜索框下面。

**详情页：首次 Pick Up**
日期是该从者**日服**首次进推荐召唤的那天，下面是当期卡池的原图 banner，
点图或卡池名跳到 Mooncell 上那个卡池的详情页。

**获取方式（475 人全覆盖）**
没有首发池的人也能说清来路：

- 首发卡池 384 人 —— 日期 + 卡池 banner
- 活动赠送 59 人 —— 活动名（可点进 Mooncell 活动页）+ 日服开服时间 + 国服时间
- 友情点召唤 30 人 —— 限期的给出「首次能抽到」的日期，常驻的就写「常驻池」
- 初始获得 2 人 —— 玛修是开局即送，阿尔托莉雅〔Lily〕是开服事前登录奖励

**卫星角色（176 条）**
数据来自 2719 件概念礼装 + 236 枚指令纹章的「出场角色 / 相关角色」字段：
在插画里出现过、但还没做成从者的人（当前 176 条），每条可点回 wiki 原文核对。

**作品人物（232 人 / 21 部作品）**
只在作品设定里存在、从未上过礼装的角色（比如《Fate/Prototype》的吉尔伽美什〔Prototype〕、
珀尔修斯、沙条爱歌），按作品分组，说明列引用 Mooncell 原文。

**缺号清单**
按职阶列出所有未实装编号，共 52 个。

**配色**
8 套配色 × 明暗两版，全部本地记忆。

## 数据来源

- **从者名单、稀有度、职阶、头像**：Atlas Academy 的日服数据
- **中文名**：国服官方 → 人工校正 → Mooncell 译名 → 日文原名
- **首发卡池 / 活动赠送**：Mooncell 的卡池页与活动页
- **卫星角色**：Mooncell 礼装、纹章的出场角色字段
- **未实装人物**：Mooncell「卫星」词条

**所有日期都是日服时间。** 国服时间只在活动赠送那一块额外给出一行。
新从者实装当天，wiki 侧的中文名与卫星记录常有半天滞后，数据会有延迟更新。
